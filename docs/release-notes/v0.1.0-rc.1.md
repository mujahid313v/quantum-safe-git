# QSGit v0.1.0-rc.1

**Status: release candidate (pre-release); experimental; not independently audited; not for production use.** This is a source-only release candidate; binaries are planned for a later release.

It includes the M0-M7 work described in [CHANGELOG.md](../../CHANGELOG.md): ML-DSA-65 Git signing and verification, key storage and trust handling, CLI verification, end-to-end coverage, CI and supply-chain checks, and security/release documentation.

Git 2.34.1 is known to fail; Git 2.39.5, 2.43.0, 2.55.0, 2.56.0, and 2.56.1 have passing runtime evidence. Other versions without passing evidence are untested. The ML-DSA backend is pre-1.0 and unaudited; revocation has no effective date; identity binding is absent; `-r` and `check-novalidate` are rejected; Windows key permissions are not enforced; and Argon2 working memory is not wiped when freed. The custom key type is not recognized by stock OpenSSH or GitHub's "Verified" badge.

Verify the signed tag using the release key and its fingerprint confirmed out of band. Check the source archive against `SHA256SUMS` for integrity; the checksum file is not signed. See [RELEASING.md](../RELEASING.md), [RELEASE-KEY.md](../RELEASE-KEY.md), and [CHANGELOG.md](../../CHANGELOG.md).
